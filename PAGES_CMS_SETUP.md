# Pages CMS setup

Pages CMS is GitHub-backed. After the repository is pushed to GitHub, sign in at Pages CMS, select the repository, and it will read `.pages.yml`. Editors create content in one of nine post collections; entries must remain drafts until editorial review.

Use media uploads only for licensed files, write meaningful cover alt text, and retain sources/disclosures. Page CMS saves to Git; Cloudflare Pages publishes only after the build succeeds.
