Browser-based participation services should be treated like any other internet account: verify the domain, protect the login, and limit what the service can access.

## Set up the account safely

Use a password manager to create a unique password. Enable multi-factor authentication if it is offered. Keep recovery codes offline, and never share verification codes with support accounts or community members.

## Keep wallet permissions separate

An account login does not justify access to a seed phrase. If a wallet is requested, connect an empty or low-value wallet and read the requested permissions. Reject unclear signatures and transactions.

## Review ongoing use

Revisit permissions after updates. Check CPU, memory, and network use if an extension is installed. Remove software that no longer has a clear purpose or current documentation.
